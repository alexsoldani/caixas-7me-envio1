# Caixas 7me — 1º Envio (Salvas Ofertório)

Kanban de acompanhamento das caixas 7me (Salvas Ofertório) do 1º envio.

- `docs/index.html` — o quadro: arrastar e soltar os cartões, filtro por pastor, busca, resumo para WhatsApp e versão para impressão.
- O andamento fica salvo no navegador de cada aparelho (localStorage). Para levar de um celular/PC para outro, use **Exportar** em um e **Importar** no outro.
- Publicado pelo GitHub Pages a partir da pasta `docs/`.

Etapas do quadro: **A imprimir → Impressas → Finalizadas → Enviadas**. O cartão representa uma igreja com a quantidade de caixas dela; o botão *Conferir* marca em verde o que já foi validado.
